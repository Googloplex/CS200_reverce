# Карта памяти LCP037BT32EU8 (LCM32F037)

Получено чтением по SWD (ST-Link V2 + pyOCD 0.45.1, `-t cortex_m`, `connect_mode=under-reset`), 2026-10-15, серва `servo_01`.
Сверено с Keil-паком `LCM32F0xx_DFP 0.4.72` (`docs/datasheets/LCM32F0xx_DFP_0.4.72/`): IROM1 0x08000000/0x8000,
IRAM1 0x20000000/0x1000, алгоритм `Flash/LCM32F037_32K.FLM`, SVD `SVD/LCM32F037.svd`, Dclock 64 МГц [ДШ].
FLM: страница = сектор = 512 Б, 64 сектора [ДШ]. pyOCD берёт цель из пака: `pyocd <cmd> --pack docs/datasheets/LCM32F0xx_DFP_0.4.72/zip/Keil.LCM32F0xx_DFP.0.4.72.pack -t lcm32f037`
(для прошивки в фазе 2). Read-only дамп + разбор журнала — `tools/dump_one.py` (цель `cortex_m`; проверен на servo_01, sha256 совпали).

## Ядро
- CPUID `0xE000ED00` = **0x410CC200** → Cortex-M0 r0p0 [ИЗМ]

## Защита
- Flash читается по отладке целиком → **RDP уровень 0** (фактически) [ИЗМ]
- Байт по 0x1FFFF800 = `0x5A` — вероятно, поле RDP; кодировку уровней не знаем [ГИП]

## Области
| Адрес | Размер | Что | Уверенность |
|---|---|---|---|
| 0x00000000 | — | зеркало Flash (вектора совпадают с 0x08000000) | [ИЗМ] |
| 0x08000000–0x08007FFF | 32 КБ | основная Flash; занято до 0x08007F7F | [ИЗМ] |
| 0x08008000–… | шаг 0x1000 | зеркало инфо-блока 0x1FFFF000 (повторяется по 0x08009000, 0x0800A000) | [ИЗМ] |
| 0x1FFFEC00 | — | не читается (memory transfer failed) | [ИЗМ] |
| 0x1FFFF000–0x1FFFF7FF | 2 КБ | системный загрузчик: SP=0x20000620, Reset=0x1FFFF0D5 | [ИЗМ]/[ГИП] |
| 0x1FFFF800–0x1FFFF9FF | 512 Б | option bytes / заводская инфо-зона | [ИЗМ] читается / [ГИП] назначение |
| 0x1FFFFA00–… | — | не читается | [ИЗМ] |
| 0x20000000 | 4 КБ | SRAM; начальный SP родной прошивки 0x20000E00 | [ДШ]/[ИЗМ] |

## Из реверса родной прошивки (подробно — `native_fw_config.md`)
- Страница Flash = 512 Б; контроллер Flash = 0x4001D000 (STM32-подобный, ключи 0x45670123/0xCDEF89AB) [ИЗМ]
- 0x08000000–0x08000FFF — загрузчик Kpower, 0x08001000 — приложение, 0x08007C00–0x08007FFF — журнал [ИЗМ]
- UART шины = 0x40015000; GPIOA = 0x48000000 [ИЗМ]

## Родная прошивка (servo_01)
- Начальный SP = 0x20000E00, Reset_Handler = 0x0800019D, NMI = 0x08000661, HardFault = 0x08000625 [ИЗМ]

## Инфо-зона 0x1FFFF800 (первые байты)
```
00: 5A 00 FF FF FA 00 FF FF FA 00 FF FF FF 00 FF FF   — формат «байт + 00 + FFFF», похоже на OB с комплементом
40: 55 AA FF FF 55 AA FF FF 65 D9 A2 01 0D FF FF FF
50: 3E 00 18 00 E8 07 0B 0A 01 00 FF FF 01 00 FF FF   — E8 07 0B 0A = 2024-11-10? (дата калибровки/производства) [ГИП]
60: 01 00 FF FF 80 00 FF FF
```
