# Распиновка платы Kpower HB200T (MCU LCP037BT32EU8)

Источник: реверс родной прошивки (`re/decomp_named.c`) + таблица AF/аналоговых функций из даташита LCP037BT32EU8
(`docs/datasheets/LCP037BT32EU8_datasheet.txt`, стр. 7–10) + SVD из Keil-пака `LCM32F0xx_DFP 0.4.72`.
[ПРОШ] = так настроено в родной прошивке (факт про код), назначение на плате — гипотеза, пока не прозвонено.

## Силовые ключи (TIM1 → встроенный предрайвер) [ПРОШ + ДШ]
| Вход предрайвера | GPIO | AF | Сигнал TIM1 | Фаза |
|---|---|---|---|---|
| HIN1 | PF4 | AF2 | TIM1_CH3 | 1 (U) |
| LIN1 | PB6 | AF4 | TIM1_CH3N | 1 (U) |
| HIN2 | PF3 | AF2 | TIM1_CH2 | 2 (V) |
| LIN2 | PB4 | AF2 | TIM1_CH2N | 2 (V) |
| HIN3 | PB7 | AF5 | TIM1_CH1 | 3 (W) |
| LIN3 | PB3 | AF1 | TIM1_CH1N | 3 (W) |

- TIM1: PSC=2 (÷3), ARR=1023, PWM mode 1, мёртвое время DTG=0x2F (47 тактов) [ПРОШ].
  Частота ШИМ = Fclk/3/1024 → **23.4 кГц при 72 МГц** (20.8 кГц при 64 МГц) [ГИП: тактовая].
- Родное управление — **шестишаговая коммутация по Холлам** (EXTI → FUN_08003754), не FOC [ГИП, сильная].

## Датчики [ПРОШ]
| Что | GPIO | Канал | Примечание |
|---|---|---|---|
| Холл A/B/C | PA4 / PA5 / PA6 | EXTI4/5/6 (IRQ7 EXTI4_15) | вход с подтяжкой |
| **Потенциометр (движок)** | PA10 | ADCIN15 | Present Position = 0xFFF − IIR(1/8) + поправка (рег. 0x14–0x15) |
| **Ток шунта** | PF6 | ADCIN11 | внутренний ОУ0 прошивкой не включается → вероятно внешний ОУ (6-выв. SOT) на PF6 [ГИП] |
| **Напряжение шины** | PA7 | ADCIN7 | рег. 0x2A = ADC × 1.13 / 10; при 24.0 В на БП показывает 20.7 → родной коэффициент занижен в ≈1.16 [ИЗМ] → реальный делитель ≈ 1:16 [ГИП: Vref 3.3 В] |
| ? | PA1 | ADCIN1 | оцифровывается, но в коде не используется (термистор не распаян?) |
| Температура | — | — | **не измеряется**: рег. 0x2B никогда не пишется |

- АЦП: 4 канала (1, 7, 11, 15), DMA → RAM 0x200003A6 (u16 ×4), запуск — триггер `0x08000000` в конфиге (вероятно от TIM1) [ПРОШ].
- Перегрузка: Present Load > 9500 дольше 1 с → Torque Limit = 0 [ПРОШ].

## Внешние площадки [ПРОШ + ИЗМ]
| Площадка | GPIO | Функция |
|---|---|---|
| **S** | PA2 | UART1 полудуплекс: AF7 = UART1_RX (приём), AF1 = UART1_TX (на время передачи) — шина Dynamixel 1.0 и загрузчик |
| S или F? | PA3 | AF0 = TIM15_CH2 (захват) + подтяжка — вероятно вход ШИМ 50–333 Гц (IRQ20 TIM15) [ГИП] |
| F? | PA0 | AF3 = TIM16_CH1 — выход (ШИМ обратной связи по положению?) [ГИП] |
| SWD | PA13 / PA14 | SWDIO / SWCLK |

## Периферия (SVD) [ДШ]
UART1 0x40015000 (IRQ28), TIM1 0x40010000, TIM15 0x4001B000, TIM16 0x4001C000, TIM17 0x4001E000, TIM14 0x4000A000,
TIM6 0x40009000, ADC 0x4001A000, ANACTRL (ОУ/компараторы/ЦАП) 0x40017C00, EXTI 0x40011000, DMAC 0x48004000,
FLASH 0x4001D000, GPIOA 0x48000000 / GPIOB 0x48000200 / GPIOF 0x48000A00 (AFRL +0x24, AFRH +0x28).
Используемые IRQ приложения: 7 EXTI4_15 (Холлы), 10 DMAC_CH1_2 (UART), 17 TIM6, 19 TIM14, 20 TIM15.

## ⚠ Для 48 В
Делитель Vbus ≈1:16 (по сверке с БП 24.0 В) → предел измерения ≈53 В при Vref 3.3 В. На 12S (до 50.4 В) впритык, но влезает;
проверить номиналы резисторов и опору АЦП, прежде чем решать про замену (Фаза 6).

## Проверить прозвонкой/замером
- PA2/PA3 ↔ площадка S (одна или обе, через что), PA0 ↔ F.
- PF6 ↔ выход 6-выводной микросхемы (внешний ОУ шунта?) и её усиление.
- PA1 — куда идёт.
- Номиналы делителя на PA7.
