# Родная прошивка Kpower (servo_01)

Источник: `dumps/servo_01/flash.bin`, Ghidra 12.1.4 (`re/decomp.c`, `re/functions.txt`, скрипты в `re/ghidra_scripts/`).
servo_01 — не золотая, можно трогать.

## 1. Раскладка Flash [ИЗМ — из кода]
| Адрес | Что |
|---|---|
| 0x08000000–0x08000FFF | **Загрузчик Kpower** (4 КБ): прошивка приложения по UART |
| 0x08001000–0x08004E53 | **Приложение** (вектора: SP=0x20000A18, Reset=0x0800119D); в конце — softfloat (`__aeabi_f*`) и данные scatter-load |
| 0x08004E54–0x08007BFF | пусто |
| 0x08007C00–0x08007DFF | журнал, сектор 0 (4 записи × 128 Б) |
| 0x08007E00–0x08007FFF | журнал, сектор 1 (4 записи × 128 Б) |

- **Страница Flash = 512 Б** (стирание шагом 0x200) [ИЗМ].
- **Контроллер Flash = 0x4001D000**, STM32-подобный: KEYR +0x04 (ключи 0x45670123/0xCDEF89AB), CR +0x10 (PG=0x01, PER=0x02, STRT=0x40, LOCK=0x80), AR +0x14 [ИЗМ].
- SysTick приложения LOAD=71999 → 1 кГц при 72 МГц [ГИП: ядро 72 МГц].

## 2. Загрузчик (0x08000000) [ИЗМ]
- После сброса ~0.2 с (SysTick 14.4М тактов) слушает UART @0x40015000; если валидных пакетов нет — прыгает в приложение 0x08001000.
- Пакет: `FD FD <ID> <LEN> … [5]=0x97 [6]=подкоманда [7..8]=u16 … данные с [11] … CHK`,
  CHK = `~sum(байты от ID)`. ID = из журнала (байт +3) или 0xFE (broadcast).
- Подкоманды: 1 — старт (размер), 2 — стереть ⌈размер/512⌉ страниц с 0x08001000
  (**при ID=0xFE ещё и стирает журнал = сброс настроек**), 3 — блок данных (буфер 512 Б → запись страницы).
- Ответ: `FD FD <ID> 07 …` (11 байт). На время передачи переключает AF вывода (GPIOA, рег. +0x24, биты 8–11: AF1 ↔ AF7) — полудуплекс на одном проводе [ГИП: это PA2 = провод S].
- Делитель UART в загрузчике: BRR int=52, frac=5 → 115200 при 96 МГц или 57600 при 48 МГц [ГИП].
- **Значит, перепрошивать сервы можно по проводу S, без SWD** (сохранив загрузчик) [ГИП, проверить].

## 3. Шина приложения — Dynamixel Protocol 1.0, эмуляция AX-12 [ИЗМ]
- Заголовок: автомат приёма проверяет `FF` и `FD` (вероятно `FF FF` — Dynamixel 1.0, `FD FD` — загрузчик) [ГИП в части FD].
- UART @0x40015000 через DMA. Скорость по умолчанию — регистр Baud=16 (в Dynamixel 2 000 000/17 ≈ 117 647 → вероятно 115200) [ГИП].
- CHK = `~sum(ID..параметры)`. Ошибки — биты Dynamixel (0x10 checksum, 0x40 instruction).
- Инструкции (диспетчер 0x0800338C):

| Код | Что |
|---|---|
| 0x01 | PING |
| 0x02 | READ |
| 0x03 | WRITE |
| 0x04 | REG_WRITE |
| 0x05 | ACTION |
| 0x06 | RESET (заводские настройки + сохранение; только при LEN=2) |
| 0x64 | **свой:** сохранить журнал и перезагрузиться (SYSRESETREQ) → вход в загрузчик |
| 0x83 | SYNC_WRITE |

- WRITE разрешён по адресам 3…0x4F, кроме 10 и 0x24…0x2E (текущие значения, только чтение).
  Запись в адреса < 0x18 (EEPROM) → флаг сохранения в журнал, если не стоит Lock (0x2F=1).

## 5. Журнал (формат исправлен) [ИЗМ]
- 2 сектора по 512 Б × 4 записи по 128 Б; запись = образ таблицы регистров 0x00–0x77 + служебное:
  - +0x78: int32 seq (максимальный = актуальный);
  - +0x7D: флаг 'Z' (0x5A = был запрос входа в загрузчик);
  - +0x7E: CHK8 = `~sum(байты 0..0x7D)`;
  - +0x7F: маркер `'K'` (0x4B) = запись валидна.
- Сохранение (0x080048F8): по флагу из главного цикла (после WRITE в EEPROM-область/RESET),
  при команде 0x64 (перед ресетом), при старте, если валидной записи нет (заводские значения).
  **При пропадании питания/ошибке — не пишет.** → журнал = история настройки, а не «чёрный ящик».
- servo_01: seq 8…14. Present Voltage в записях: seq 8–12 → 10.6 В, seq 13–14 → 13.9 В
  (две разные сессии настройки с разным питанием). Goal 1000/2000 ↔ Present 1190…2936.
